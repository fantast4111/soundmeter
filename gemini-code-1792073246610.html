🧭 麥克風權限與功能指南

🔴 為什麼點「啟動」沒有任何反應？

如果您是直接「雙擊點開」下載下來的 HTML 檔案，網址列會顯示為 file:///...。現代瀏覽器基於資訊安全，會直接禁止任何在地檔案開啟麥克風權限，並且不會彈出詢問視窗。

🛠️ 三個快速解決方案

  • 推薦方法一 (最簡單)：使用 Firefox (火狐瀏覽器) 開啟這個檔案，通常能直接成功彈出權限請求！
  • 推薦方法二 (手動允許)：觀察網址列左側，點擊「驚嘆號 ⚠️」、「鎖頭 🔒」或「控制滑桿」圖示，手動將麥克風設為「允許」。
  • 免硬體測試：點擊右下角「開啟模擬測試」，可以直接用拖動滑桿的方式，模擬教室聲音，測試累積計時功能。

📋 秩序管理教學建議

1. 在教室安靜時觀察「目前教室音量」落在哪個分貝數（假設為 45dB）。
2. 將閥值滑桿往右調整到 15~20 dB 左右（設為 65dB）。
3. 與學生約定：當計時器跑超過 1 分鐘，可能就要進行秩序調整，能有效將「秩序」視覺化，讓學生學會自主控制音量！

### 💡 改進設計特點： * **防安全限制鎖死**：當你在桌面直接雙擊開啟 HTML（導致麥克風無法被瀏覽器啟用）時，右下角的 **「開啟模擬測試」** 能讓您在完全沒有麥克風硬體的情況下，手動調節環境噪音進行計時器、閥值紅線、動態波形與秩序累積時間的功能測試。 * **無痛權限重啟**：內建精美的 **自訂對話框模式 (Modal)** 取代了會使人煩躁的瀏覽器 `alert()`，並提供直接的手動排除障礙步驟。 * **高對比現代儀表板**：採用深色太空灰 (Space Gray) 風格，亮綠、亮黃與霓虹粉的漸層進度條能更突出「超標」時的視覺衝擊，對於台下的學生具有更好的警示效果。
